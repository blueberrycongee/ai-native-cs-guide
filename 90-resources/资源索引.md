# 资源索引

这里放跨方向的高质量资料。资源索引不是越长越好，每个链接都要说明适合什么时候看。

## 公共基础

- [Attention Is All You Need](https://arxiv.org/abs/1706.03762)：学 [[Transformer]] 和 [[Attention]] 时看结构，不要一开始卡在公式。
- [The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/)：适合第一次建立模型结构直觉。
- [Hugging Face Transformers docs](https://huggingface.co/docs/transformers)：看开源模型如何在工程里使用。

## 应用工程

- [MDN HTTP overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview)：补 [[HTTP]] 基础。
- [MDN Server-sent events](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events)：做 [[SSE]] 流式输出时查。
- [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/)：做 [[Agent]] 或 [[RAG]] 前先看风险分类。

## Agent

- [ReAct paper](https://arxiv.org/abs/2210.03629)：理解 [[Agent Loop]] 和 [[Tool Use]] 的经典入口。
- [OpenAI Codex docs](https://developers.openai.com/codex)：观察 coding agent 的产品和工作流形态。
- [Model Context Protocol](https://modelcontextprotocol.io/docs)：了解工具和上下文接入的一种标准化方向。

## 训练和对齐

- [nanoGPT](https://github.com/karpathy/nanoGPT)：用小代码库理解 [[Pre-Train]]。
- [InstructGPT paper](https://arxiv.org/abs/2203.02155)：理解 [[Post-Train]] 和 RLHF。
- [Direct Preference Optimization](https://arxiv.org/abs/2305.18290)：了解偏好优化。
- [OpenAI Spinning Up](https://spinningup.openai.com/)：补 [[RL]] 基础。
