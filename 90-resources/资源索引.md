# 资源索引

这里放跨方向的高质量资料。资源索引不是越长越好，每个链接都要说明适合什么时候看。项目推荐以一手资料为主：官方文档、论文、README、examples 和源码入口。

## 公共基础

- [Attention Is All You Need](https://arxiv.org/abs/1706.03762)：学 [[Transformer]] 和 [[Attention]] 时看结构图、第 3 节和实验设置。
- [The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/)：第一次建立 Transformer 直觉时看。
- [Hugging Face Transformers](https://huggingface.co/docs/transformers)：看开源模型如何加载、生成和训练。
- [nanoGPT](https://github.com/karpathy/nanoGPT)：用小代码库理解 GPT 训练，先看 `model.py` 和 `train.py`。

## 经典论文深挖

- [[经典论文深挖]]：跨方向论文入口，用来判断哪些论文值得深读、读到什么程度、如何连接到项目实践。
- [[论文阅读路线]]：按公共基础、训练、后训练、推理系统和 Agent 分层安排论文阅读顺序。
- [[Attention Is All You Need]]：第一篇完整深挖样例，重点连接 [[Transformer]]、[[Attention]]、[[Inference]] 和 nanoGPT。

## AI 应用工程

- [MDN HTTP overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview)：补 [[HTTP]] 请求、响应、header 和状态码。
- [MDN Server-sent events](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events)：做 [[SSE]] 流式输出时查事件格式。
- [MDN WebSocket API](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API)：需要双向实时通信时看。
- [OWASP API Security Top 10](https://owasp.org/API-Security/)：做 [[API Auth]] 和后端接口前看。
- [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/)：做 [[Agent]]、[[RAG]] 或工具调用前看风险分类。

## RAG 和上下文

- [LlamaIndex docs](https://docs.llamaindex.ai/)：看 ingestion、index、query engine、agent 和 evaluation。
- [Haystack docs](https://docs.haystack.deepset.ai/docs/intro)：看 pipeline、component 和 document store 的工程组织。
- [Qdrant docs](https://qdrant.tech/documentation/)：看 collection、payload filter、hybrid search 和部署。
- [Milvus docs](https://milvus.io/docs)：看向量库架构、索引和大规模部署。
- [Anthropic Contextual Retrieval](https://www.anthropic.com/news/contextual-retrieval)：看给 chunk 补上下文的一种检索改进。

## Agent

- [ReAct paper](https://arxiv.org/abs/2210.03629)：理解 [[Agent Loop]] 和 [[Tool Use]] 的经典入口。
- [LangGraph docs](https://docs.langchain.com/oss/python/langgraph)：看 durable execution、streaming、memory 和 human-in-the-loop。
- [OpenAI Agents SDK](https://platform.openai.com/docs/guides/agents-sdk/)：看 agent、tool、handoff 和 tracing。
- [Microsoft AutoGen](https://autogenhub.github.io/autogen/docs/Use-Cases/agent_chat/)：看多 agent 对话框架。
- [CrewAI docs](https://docs.crewai.com/en/index)：看 crew、flow 和任务编排的另一种抽象。
- [Model Context Protocol](https://modelcontextprotocol.io/docs)：了解工具和上下文接入的一种标准化方向。

## 训练、后训练和 RL

- [LitGPT](https://github.com/Lightning-AI/litgpt)：看 pretrain、finetune、evaluate、deploy 的统一工作流。
- [Megatron-LM](https://github.com/NVIDIA/Megatron-LM)：看大规模 Transformer 训练和并行策略。
- [TRL](https://huggingface.co/docs/trl)：看 SFT、DPO、GRPO、reward model 等后训练方法。
- [Axolotl](https://docs.axolotl.ai/)：看配置驱动的 LLM fine-tuning。
- [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory)：看多模型微调和 WebUI 工作流。
- [OpenRLHF](https://github.com/OpenRLHF/OpenRLHF)：看 Ray、vLLM 和 RLHF/GRPO 的工程化训练。
- [Gymnasium](https://gymnasium.farama.org/)：学 [[RL]] 环境接口时先看。
- [CleanRL](https://github.com/vwxyzjn/cleanrl)：读单文件强化学习算法实现。
- [Stable-Baselines3](https://stable-baselines3.readthedocs.io/)：需要可靠 baseline 时看。
- [RLlib](https://docs.ray.io/en/master/rllib/index.html)：需要分布式或多 agent RL 时看。
