# 论文地图

这页按问题类型整理论文，不按年份或热门程度排列。

## 深度学习架构基石

这一层解决“现代深度网络为什么能训练得更深、更大”。

- `ImageNet Classification with Deep Convolutional Neural Networks`：理解 AlexNet、GPU 训练、ReLU、Dropout 和 ImageNet 对深度学习工程化的影响。
- `Deep Residual Learning for Image Recognition`：理解 ResNet 的 residual connection，重点看 identity shortcut 为什么让很深的网络更容易优化。
- `Attention Is All You Need`：连接 [[Attention Is All You Need]]、[[Transformer]] 和 [[Attention]]，核心是 self-attention、multi-head attention、position encoding 和 encoder/decoder block。

相关代码和实验：

- 用 torchvision 或 timm 加载 ResNet，找到 residual block 里的 shortcut。
- 对比一个普通卷积 block 和 residual block，解释为什么输出可以写成 `x + F(x)`。
- 用 nanoGPT 看 `model.py` 里 Transformer block 如何落地。

## 语言模型架构和位置编码

这一层解决“现代语言模型为什么长这样，以及上下文位置如何进入模型”。

- `BERT`：理解 encoder-only 预训练、mask language modeling 和分类/检索任务里的表示学习。
- `RoFormer: Enhanced Transformer with Rotary Position Embedding`：理解 RoPE 如何把相对位置信息编码进 query/key 的旋转变换。
- `Language Models are Unsupervised Multitask Learners`、`Language Models are Few-Shot Learners`：理解 GPT 路线、自回归生成、scaling 和 [[Prompting]]。

相关代码和实验：

- 用 Hugging Face Transformers 加载一个 encoder 模型和一个 decoder 模型，比较输入输出形态。
- 在支持 RoPE 的模型实现里找到 position embedding 相关代码，确认它不是简单的 absolute position table。
- 解释为什么聊天模型生成时必须逐 token decode。

## 训练和 scaling

这一层解决“模型能力从哪里来，以及训练为什么这么贵”。

- `Dropout: A Simple Way to Prevent Neural Networks from Overfitting`：理解正则化为什么会影响泛化。
- `Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift`：理解训练稳定性和归一化层的工程意义。
- `Adam: A Method for Stochastic Optimization`：理解 optimizer 为什么是训练配置的一部分。
- `Scaling Laws for Neural Language Models`：理解参数、数据、算力和 loss 的经验关系。
- `Training Compute-Optimal Large Language Models`：理解 Chinchilla 对数据量和模型大小配比的影响。

相关代码和实验：

- 读 [[Training Loop]] 和 nanoGPT `train.py`。
- 跑一个小训练实验，保存 loss 曲线、配置和生成样例。
- 改 context length 或数据集，观察 loss 和生成结果变化。

## 后训练和对齐

这一层解决“基础模型怎样变成可用助手或任务模型”。

- `Training language models to follow instructions with human feedback`：理解 SFT、reward model、PPO 和用户偏好。
- `Direct Preference Optimization`：理解 [[DPO]] 为什么能用 chosen/rejected 数据直接优化偏好。
- `Constitutional AI`：理解规则、反馈和安全边界如何进入训练流程。

相关代码和实验：

- 用 TRL 跑一次 [[SFT]] 或 DPO 小实验。
- 用同一组 [[Evals]] 比较训练前后输出。
- 分开记录格式遵循、事实正确、拒答和任务成功率。

## 推理系统

这一层解决“为什么模型服务不是简单跑一次 forward”。

- `FlashAttention`：理解 attention 计算为什么受显存读写影响。
- `Efficient Memory Management for Large Language Model Serving with PagedAttention`：理解 KV cache、分页和连续 batching。
- Megatron-LM 和 DeepSpeed 相关论文：理解大模型训练和服务里的并行策略。

相关代码和实验：

- 读 [[Inference]]、[[Inference Serving]] 和 [[GPU Basics]]。
- 用 vLLM 或 llama.cpp 跑同一个模型，观察首 token 延迟、吞吐和显存。
- 解释 batch、KV cache 和 context length 如何影响成本。

## Agent 和工具使用

这一层解决“模型如何进入任务循环，而不是只生成一段文本”。

- `ReAct`：理解 reasoning 和 action 交替，以及 [[Agent Loop]]、[[Tool Use]] 的基本形态。
- `Toolformer`：理解工具使用数据如何被构造进模型训练。
- `WebGPT`：理解浏览、引用、反馈和真实任务评测。

相关代码和实验：

- 做一个最小工具调用 agent，记录每一步输入、工具输出和最终答案。
- 给 agent 加 [[Evals]]，记录多次任务结果。
- 复盘一次失败：是模型判断错、工具结果错、上下文拼接错，还是权限和重试设计错。
