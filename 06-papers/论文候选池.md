# 论文候选池

这个文件记录后续可以深挖的论文。候选池不是阅读任务清单，也不是引用量排行榜。论文只有在能连接到仓库里的概念、方向或项目验证时，才会从候选变成正式文章。

每篇正式深挖会回答：它解决了什么问题，今天还影响哪些系统，论文里哪些部分关键，以及如何连接到代码或项目。

## 深度学习架构基石

- `ImageNet Classification with Deep Convolutional Neural Networks`：AlexNet。GPU 训练、ReLU、Dropout、ImageNet 和现代深度学习工程化的起点。
- `Very Deep Convolutional Networks for Large-Scale Image Recognition`：VGG。“堆深度”的直觉和局限，为 ResNet 做铺垫。
- `Deep Residual Learning for Image Recognition`：ResNet。重点是 residual connection、identity shortcut 和深层网络优化。
- `Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift`：BatchNorm。训练稳定性、归一化层和工程副作用。

验证入口：

- 用 torchvision 或 timm 读 ResNet block。
- 对比没有 shortcut 的深层网络和 residual block。
- 观察训练曲线，而不是只看最终准确率。

## Transformer 和位置编码

- `Attention Is All You Need`：Transformer 原始论文。已经有 [[Attention Is All You Need]]。
- `RoFormer: Enhanced Transformer with Rotary Position Embedding`：RoPE。重点是旋转位置编码、相对位置关系和长上下文模型里的实现形态。
- `Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation`：ALiBi。和 RoPE 对比不同位置编码对长度外推的影响。
- `BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding`：BERT。encoder-only、MLM 和表示学习。
- `Language Models are Unsupervised Multitask Learners`、`Language Models are Few-Shot Learners`：GPT 路线、prompting 和 in-context learning。

验证入口：

- 在 Hugging Face Transformers 里找 RoPE 或 absolute position embedding 的实现。
- 比较 encoder-only 和 decoder-only 模型的输入输出。
- 用 nanoGPT 理解 causal attention 和自回归训练。

## 训练、优化和 scaling

- `Adam: A Method for Stochastic Optimization`：优化器为什么会影响训练稳定性和收敛速度。
- `Dropout: A Simple Way to Prevent Neural Networks from Overfitting`：正则化和泛化。
- `Scaling Laws for Neural Language Models`：参数、数据、算力和 loss 的经验关系。
- `Training Compute-Optimal Large Language Models`：Chinchilla。重点是 compute-optimal 视角下的数据和模型规模配比。

验证入口：

- 跑一个小训练实验，保存配置、loss 曲线和样例输出。
- 改 optimizer、学习率或数据量，观察结果变化。
- 不把 loss 下降直接等同于真实任务能力提升。

## 后训练和对齐

- `Training language models to follow instructions with human feedback`：InstructGPT。重点是 SFT、reward model、PPO 和用户偏好。
- `Direct Preference Optimization: Your Language Model is Secretly a Reward Model`：DPO。重点是 chosen/rejected 数据和 reference model。
- `Constitutional AI: Harmlessness from AI Feedback`：规则、反馈和安全边界如何进入训练。
- `DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models`：可作为 GRPO 相关路线的入口，但需要和具体 post-training 工程分开写。

验证入口：

- 用 TRL 跑 SFT 或 DPO 小实验。
- 用同一组 [[Evals]] 比较训练前后。
- 分开记录格式遵循、事实正确、拒答和任务成功率。

## 推理系统和高性能实现

- `FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness`：attention 的瓶颈不只是 FLOPs，还有显存读写。
- `FlashAttention-2: Faster Attention with Better Parallelism and Work Partitioning`：进一步理解并行和 kernel 设计。
- `Efficient Memory Management for Large Language Model Serving with PagedAttention`：vLLM。重点是 KV cache 管理和连续 batching。
- Megatron-LM、DeepSpeed 相关论文：理解张量并行、流水线并行和大规模训练系统。

验证入口：

- 用 vLLM 或 llama.cpp 跑同一模型，观察首 token 延迟、吞吐和显存。
- 改 batch size、context length、并发数，记录系统行为。
- 解释为什么推理服务不是简单调用一次 `model.forward`。

## Agent 和工具使用

- `ReAct: Synergizing Reasoning and Acting in Language Models`：reasoning/action 交替，连接 [[Agent Loop]] 和 [[Tool Use]]。
- `Toolformer: Language Models Can Teach Themselves to Use Tools`：工具使用数据如何被构造出来。
- `WebGPT: Browser-assisted question-answering with human feedback`：浏览、引用和人类反馈如何连接。
- `Voyager: An Open-Ended Embodied Agent with Large Language Models`：长期技能库、环境交互和自动课程设计。

验证入口：

- 做一个最小工具调用 agent，记录完整 trace。
- 给 agent 加 eval，不只看单次成功 demo。
- 复盘失败来自模型、工具、上下文、权限还是重试策略。
