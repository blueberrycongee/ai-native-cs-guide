# 经典论文深挖

经典论文深挖不是论文列表。它要帮助读者把论文里的关键思想连接到今天的 AI Native 系统：模型结构、训练流程、后训练、推理服务、Agent 循环、评测和工程取舍。

这个模块只收对仓库主线有长期价值的论文。判断标准不是引用量或名气，而是它是否解释了一个今天仍然反复出现的问题。

## 怎么选论文

优先收这些论文：

- 能解释公共基石，例如 [[Transformer]]、[[Attention]]、[[Embedding]]、[[Inference]]。
- 能帮助理解重点方向，例如 [[Pre-Train]]、[[Post-Train]]、[[RL]]、[[AI Infra]]、[[Agent]]。
- 能连接真实项目或代码实现，例如 nanoGPT、Megatron-LM、vLLM、TRL、LangGraph。
- 能暴露重要取舍，例如上下文长度、训练数据、偏好优化、KV cache、奖励设计、工具调用可靠性。

暂时不收这些内容：

- 只因为热门但和仓库学习路径无关的论文。
- 只能做成公式推导、但无法连接工程实践的论文。
- 二手资料已经足够、没有必要单独深挖的论文。
- 没有明确验证任务的论文。

## 每篇深挖应该回答什么

一篇论文深挖至少要回答：

- 论文解决的具体问题是什么。
- 它引入了哪些关键抽象。
- 今天哪些系统仍然受它影响。
- 读论文时应该先看哪些章节、图和实验。
- 它最容易被误读的地方是什么。
- 读完后应该用什么项目、代码或小实验验证。

复杂公式可以解释用途和直觉，但不必完整重写推导。这个仓库更关心论文如何改变系统设计，而不是把论文变成课本。

## 推荐阅读顺序

先看 [[论文阅读路线]] 和 [[论文候选池]]。不要按年份硬读，也不要从最新论文开始追。

推荐顺序是：

1. 先读深度学习架构基石，理解卷积、残差连接、attention 和 Transformer。
2. 再读位置编码和上下文机制，理解 RoPE、长上下文和自回归生成。
3. 再读训练和 scaling，理解数据、loss、batch、算力和模型能力的关系。
4. 进入后训练，理解 SFT、偏好优化、RLHF 和 eval。
5. 补推理系统，理解 KV cache、batching、显存和吞吐。
6. 最后看 Agent 和工具使用，把模型能力放回真实任务循环。
