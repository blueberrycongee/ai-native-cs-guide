# Cost

Cost 是 AI 项目能不能长期运行的基本约束。模型调用、embedding、向量检索、推理部署、日志存储和评测都会产生成本。

相关概念：

- [[Token]]
- [[Context Window]]
- [[Inference]]
- [[Prompt Cache]]
- [[RAG]]

## 为什么值得学

很多 demo 看起来能跑，但一旦有真实用户就撑不住：

- prompt 太长
- RAG 检索返回太多内容
- Agent 多轮循环没有上限
- 重试策略让失败请求重复烧钱
- 日志和 eval 没有抽样策略

成本不是最后才优化的问题。它会反过来影响产品形态和系统设计。

## 学到什么程度

先学会估算：

- 每次请求大约消耗多少 token
- 首 token 和完整响应延迟是多少
- 每个任务最多允许多少轮模型调用
- 哪些上下文可以缓存
- 哪些任务需要更便宜的小模型

不用一开始做复杂成本平台。先把 token、请求次数和失败重试记下来。

## 在项目里怎么出现

做 [[Agent]] 时，最容易失控的是循环。一次用户请求可能变成多次模型调用、多次工具调用和多次 RAG 检索。

做 [[RAG]] 时，最容易浪费的是把太多无关 chunk 放进上下文。

做推理服务时，最容易忽视的是并发和峰值负载。
