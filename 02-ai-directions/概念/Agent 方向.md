# Agent

在方向地图里，Agent 指一类让模型围绕目标、上下文、工具和反馈循环工作的系统。

## 为什么值得学

Agent 是 AI 应用开发里最容易做出真实项目的一条路。它不要求你先训练模型，但会逼你面对真实工程问题：工具权限、上下文管理、任务拆分、失败恢复、评测和成本。

它也最容易被营销词污染。一个聊天框加几个 API 不是 Agent。判断标准不是它有没有“自主”这个词，而是它是否真的能在反馈里调整行动。

## 入门边界

先学到能做一个小系统：

- 明确输入目标
- 维护任务上下文
- 调用一两个工具
- 根据工具结果继续下一步
- 用简单 eval 判断结果是否可用

暂时不要追求复杂 multi-agent。多 Agent 不是单 Agent 没做好的补丁。
